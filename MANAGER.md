# Shop manager views

Seven primary routes: overview, actions, products, ads, creators, forecast, sources. Existing detailed routes remain under the secondary menu.

Manager sources are collection requirements, not a statement that every export field is available. Exact account-specific submenu names are marked for verification. No raw XLSX parser or live TikTok connection is included.

Existing evidence storage and numerical forecast engines are preserved. Task status/owner/due/note are local per-brand storage under bg-manager-tasks:v1:<brandId> and can be exported independently as CSV.

Never publish user evidence or test import JSON in this repository.
